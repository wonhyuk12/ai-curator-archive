# AI 큐레이터 프로토타입 (에러없조)

AI 회사들의 공식 발표를 모아 두 문장으로 요약해 보여주는 웹 서비스의 디자인 프로토타입이에요.
- **실제 데이터**: AI 진화 타임라인, LLM 차트의 모델 이름·출시일·기능, 요금(API·무료·Pro·Max), 급상승(OpenRouter), 알림함
- **예시 데이터**: 화제성 점수·등락률, 주요 소식, 작업물, 상단 지수 카드 — 화면에도 `예시` 표시가 붙어 있어요

## 여는 법

`index.html`을 더블클릭하면 브라우저에서 바로 열려요. (저장소 맨 위에서 `npm run dev` 하면 AI ARCHIVE와 함께 열려요 → http://localhost:3001)
VS Code를 쓰면 Live Server 확장으로 열면 저장할 때마다 자동 새로고침돼요.

## 폴더 구조

```
ai-curator/
├─ index.html      화면 뼈대 (헤더, 지수 카드, LLM 차트, 카테고리, 소식 영역)
├─ css/style.css   색, 글꼴, 레이아웃 (맨 위 :root 에 색 변수가 모여 있음)
├─ js/data.js      데이터만 있는 파일 ← 내용 바꿀 땐 여기만 고치면 됨
├─ js/app.js       화면 그리는 코드 (차트, 필터, 상세창, 검색, 알림)
└─ logos/          모델 로고 이미지
```

## 자주 고치는 곳 (js/data.js)

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| 소식 추가·수정 | `NEWS` |
| LLM 차트에 모델 추가 | `MODELS` (+ 로고는 `MODEL_LOGOS`) |
| 카테고리 버튼 | `PERSONAS` |
| 소식 종류 버튼 | `TYPES` |
| AI 검색 예시 결과 | `SEARCH` |
| AI 진화 타임라인 (실제 데이터) | `TIMELINES` — 날짜 오래된 순, 항목마다 `source`(출처 링크) 필수 |
| AI 계열 정보·검색 별명 | `FAMILIES` (`aliases`로 검색하면 계열 종합 화면이 열림, `now` = 현재 라인업) |
| 특정 모델 별명 | `MODEL_ALIASES` (예: "소네트" → Claude Sonnet) |
| 타임라인 조사 날짜 | `TIMELINE_CHECKED` |
| 회사 정보·원문 링크 | `COMPANIES` |

새 로고는 `logos/` 폴더에 PNG를 넣고 `MODEL_LOGOS`에 `"logos/파일이름.png"`로 적으면 돼요.
정사각형, 흰 배경, 로고가 가운데 2/3 정도 크기면 동그라미 안에 딱 맞아요.

## 합칠 때 팁

- 내용(소식, 모델)만 바꾸는 사람은 `js/data.js`만, 디자인 바꾸는 사람은 `css/style.css`만 건드리면 충돌이 거의 안 나요.
- 새 화면(페이지)을 만들면 `index.html`처럼 `css/style.css`를 불러오면 같은 색·글꼴이 그대로 적용돼요.
- 스크립트 순서는 꼭 `data.js` → `app.js` 순서로 둬야 해요.

## AI 진화 타임라인 (실제 데이터)

- LLM 차트에서 모델을 누르면 **진화** 탭이 먼저 열려요. 검색창에 `gpt`, `클로드`, `제미나이`, `딥시크`처럼 AI 이름을 치면 그 계열 종합 화면이 열려요.
- `TIMELINES`는 각 회사 공식 발표(블로그·문서)를 1순위로 조사한 **실제 데이터**예요. 나머지(화제성 점수·소식 등)는 여전히 예시 데이터라서 화면에 `예시` 표시를 달아 뒀어요.
- 새 AI 계열 추가: `FAMILIES`와 `TIMELINES`에 같은 키로 한 줄씩 추가하고, 차트 모델이 있으면 `MODELS`의 `family`에 그 키를 적으면 돼요.
- 날짜를 일(日)까지 확인 못 하면 `date: "YYYY-MM"`, `precision: "month"`로 적어요.
