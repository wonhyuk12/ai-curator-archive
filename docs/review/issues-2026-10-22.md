# 점검에서 찾은 문제 (2026-10-22)

800×480 터치 화면을 처음 온 사람처럼 따라가 보고, 화면 문구와 데이터를 대조해 찾은 문제예요.
처리 우선순위: 틀린 정보 > 막히는 곳 > 헷갈리는 말 > 빠진 정보

## 틀린 정보
| 위치 | 문제 | 처리 |
|---|---|---|
| 작업별 추천 > 공부·글쓰기·연구의 노트 툴 추천 문구 | NotebookLM은 2026-07-16에 Gemini Notebook으로 이름이 바뀜 | 추천 문구 3곳 수정 (툴 설명의 "구 NotebookLM" 안내는 유지) |
| Luma AI 툴 설명 | 버전명 "Ray3.2"를 공식 자료로 확인 못 함 | 버전명 없이 일반 설명으로 |
| AI 소식 > GPT-6.1 Sol 소식 링크 | OpenAI 원문이 자동 확인을 막아 내용 확인 불가 | 같은 내용을 보도한 TechCrunch 기사로 교체 |

## 막히는 곳
| 위치 | 문제 | 처리 |
|---|---|---|
| 툴 패널 (여러 작업에 나오는 툴 32개, 102개 항목) | 툴마다 설명이 하나라 어느 작업에서 열어도 같은 내용. 예: 개발 > 디자인의 Gemini에 "Gmail 연동, 긴 문서 분석" | 항목마다 그 작업 전용 "이 작업에서 좋은 점"·"이렇게 써 보세요" 작성 |
| 알림함 | 한 손님이 열면 다음 손님부터 전부 읽음으로 보임 | 키오스크는 새 손님(세션)마다 읽음 기록 초기화 |
| 설문 말풍선 | 툴 패널·알림함 위를 가리고 눌리기까지 함 | 창이 열려 있으면 띄우지 않고, 떠 있다가 창이 열리면 바로 숨김 |
| 툴 패널·모델 상세 | 마지막 내용이 아래 고정 버튼(처음으로·설문)에 가림 | 키오스크에서 아래 여백 추가 |
| 마인드맵 (800×480) | 왼쪽 위 안내 글씨가 분야 노드 글씨와 겹침 | 높이 520px 이하 화면에서 안내 숨김 |

## 헷갈리는 말
- 툴 패널 라벨 "이 작업엔 이걸 써라"(명령조) → "이 작업에 추천하는 이유". 맨 아래 "NODE_ID" 개발용 글자 삭제
- 어려운 말 풀어 쓰기: 핸드오프, Dev Mode, 스펙, 멀티모달, 컨텍스트, 워크플로, PR 리뷰, RLS, 노코드, CMS, SEO, 퍼블리시, 임베드, 에셋, 리메시, VFX, TTS, 롱폼, 키비주얼, 무드보드, IA 설계, MVP, #LLM
- 과장 표현 고치기: "최강", "넘을 툴이 없어요", "압도적인", "가장 충실", "가장 정확", "가장 자연스러운", "최고 수준의"
